# 华为 / 鸿蒙 · 安装与首启引导

> 这份文档的定位：**在点安装之前就该读到它**。
> 应用拦不住自己的安装失败 —— 装不上时它根本没在运行，所以任何「应用内报错」都指望不上。
> 应用内的同一份内容在「设备体检」页顶部，可一键复制。

---

## 一、安装阶段

### A. HarmonyOS 4.x / EMUI（大多数华为机）

| 步骤 | 路径 | 说明 |
|---|---|---|
| 1 | 设置 → 系统和更新 → 纯净模式 → **退出纯净模式** | 纯净模式会拒绝一切应用市场之外的安装，提示语还特别含糊（「应用来源未知」） |
| 2 | 设置 → 安全 → 更多安全设置 → **安装外部来源应用** | 把「文件管理」或你用来打开 APK 的应用设为「允许」 |
| 3 | 打开 APK → 出现「未经华为检测」时选 **继续安装** | 这是华为对所有非市场上架应用的统一提示，与 APK 本身无关 |
| 4 | 若第三方分发器（应用宝等）拒绝安装 | 改用系统「文件管理」直装即可绕过 —— 那是分发器策略，不是包的问题 |

**安装失败对照表**

| 报错 | 含义 | 处理 |
|---|---|---|
| 应用来源未知 / 已被拦截 | 纯净模式在拦 | 回到步骤 1 |
| 未经华为检测 | 常规提示 | 选「继续安装」 |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | 设备架构与包内 ABI 不匹配 | 本包含 `arm64-v8a` + `x86_64`，华为机应命中前者；出现该错说明拿到的是纯 x86_64 包 |
| 与已有应用签名冲突 | 同包名不同签名 | 本包名是 `io.dsh.fusion`，与其它 DSH 安卓版**不冲突**，可并排安装 |
| 解析包时出现问题 | APK 传输损坏 | 比对 sha256（见下） |

### B. HarmonyOS NEXT（5.0 及以上）

**APK 无法直接运行** —— NEXT 已经移除 AOSP 兼容层，这是系统级事实，不是本项目的缺陷。
需要在「卓易通」等兼容层里运行。

装好后可在应用内「设备体检」页看到「鸿蒙兼容层」一项，它会自动判断你处在哪个环境：

- `HarmonyOS 4 及以下（AOSP 内核，APK 直接可用）` → 判绿；
- `HarmonyOS NEXT + 兼容层运行` → 判黄，并提示 PROOT 后端可能因 ptrace 被拦而失效，建议切「原生直跑」；
- `HarmonyOS NEXT 原生环境` → 判红，并指向 HAP 形态（见 [README 演进方向](HUAWEI-INSTALL.md#三后续演进hap)）。

## 二、首次启动：它不是卡死，是在下载

内置运行时（Node 24.18 + PRoot 5.1.107）随 APK 提供，**不需要下载**。
但下面三样要联网取：

| 项目 | 体积 | 触发时机 | 必选 |
|---|---|---|---|
| `@deepseek-ai/dsh` 内核 + web profile | 数百 MB | 首启向导点「开始装配」 | ✅ |
| Ubuntu rootfs | 约 30 MB（展开约 300 MB） | 设置 → 下载与内核 → 「装配」 | ⭕ |
| 离线唤醒模型 | 约 42 MB | 设置 → 语音 → 「下载」 | ⭕ |

**判断它有没有死的唯一标准：切到「控制台」页，看日志有没有在滚。**
只要还在滚字，就是在正常下载；进度也实时显示在首启向导的状态行上。

下载全部走国内镜像（npm → npmmirror；rootfs → 清华 / 中科大 / cdimage 三源轮询），
带断点续传与 sha256 校验，中断可以重来，npm 缓存会复用。

## 三、装好后的三件事

1. **电池优化白名单**（华为最见效的一步）
   设备体检 → 「电池优化 / 后台保活」 → 点「去加入白名单」 → 系统弹窗里选「允许」。
   华为的后台清理比原生 Android 激进得多，引擎虽然是前台服务，仍可能被冻结子进程。

2. **通知权限**
   允许通知。Android 13+ 不授权时，前台服务的常驻通知不显示，
   你会以为应用在偷偷跑 —— 这一条体检页会单独报出来。

3. **无障碍服务**（想用截屏 / 手势 / 读屏类工具时）
   设备体检 → 「无障碍服务」 → 「去开启」。

---

## 四、出问题看哪里

主界面底部 →「控制台」页：完整日志，可「仅错误」过滤，右上角一键复制。
把复制的全文贴到任何地方都能定位问题环节。
「设备体检」页会把 17 项环境检查逐条摆成红黄绿，能修的给按钮，不能修的给路径。

## 五、校验包完整性

```bash
sha256sum DSH-Fusion-v1.0.0-universal.apk
```

D 盘上的 APK 旁边有一份 `DSH-Fusion-v1.0.0-universal.apk.sha256`，两边对得上再装。
